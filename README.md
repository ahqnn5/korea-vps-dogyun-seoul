## 87ms 背后：三网各自的去程和回程

国内平均 87ms 这个数字来自第三方测评，测试节点覆盖主流城市，同一批测评里本地测速基本能跑满标称的 30Mbps。韩国到华北、华东的物理距离短，这个延迟在亚洲机房里属于靠前水平。

拆到运营商层面，情况比一句“三网直连”复杂一点：

- 电信：弹性云去程走 CN2，经典云去程走 163，两者的回程都是 CN2 GIA。
- 移动：去程、回程都是 CMI 直连。
- 联通：去程、回程都是 AS4837 直连。

这里有个细节值得单独说。两份第三方测评对电信去程的说法不一致：其中一份写“电信去程和回程都走 CN2”，没有区分产品线；另一份更细，明确弹性云去程是 CN2、经典云去程是 163。颗粒度更细的那份更可信，但两份都是第三方推广文，不是官方文档，所以准确表述应该是“第三方测评显示弹性云在电信去程上比经典云更优”。

对电信用户来说，这几毫秒的差别在晚高峰更明显。移动和联通用户不用纠结，两条产品线的去回程走法一样。

硬件方面，测评机型是 Intel Xeon E5-2697A（1 核 2.6GHz），SSD RAID，fio 读写约 319MB/s，UnixBench 单核约 1023 分。这个成绩跑 WordPress、Typecho、轻量 API 够用，跑重负载编译会吃力，后者更适合弹性云临时拉高配置。

IP 归属地是韩国首尔，本地流媒体和本地服务会识别为韩国用户。个别平台未必能解，按实际测试为准；做韩区业务前，建议先开一台按小时机验证自己要看的那几个站。

## 经典云和弹性云，差别不只在“灵活”两个字

经典云是固定套餐：配置写死，开通后不能升配也不能降配，续费价和首购价一致。流量跑完之后不会停机断网，只是带宽被压到最低档，下一个计费月自动清零。这个设计对小站比较友好，超了流量网站还能打开，只是慢。

弹性云按“固定硬件费 + 流量费”计费，流量单价 ¥0.10/GB，按小时结算，最低每小时 ¥0.0470。它的功能列表比经典云长：面板里一键重装系统、提工单挂自定义 ISO、暂停留机（暂停期间只扣硬盘和 IPv4 费用，CPU 和内存不计费）、自助更换 IPv4/IPv6、随时销毁退余额。韩国机房目前只有“优化”一条线路，没有可切换的多线选项，这一点和香港机房不同。

第三方文章还提到一个“机龄计划”：机器用得越久，每小时免费流量上限越高，最高累计 6 个月可拿到 210MB/小时、约 151GB/月的免费流量。这条只有单一来源，当成参考就好，不要按它做预算。

## 韩国机房给不了的东西

30Mbps（经典云）和 50Mbps（弹性云）是韩国机房的上限。韩国出口带宽贵是行业现状，这个数字在当地算主流起步配置，但放到具体业务上就有边界：

- 下载站、镜像站、视频分发这类吃带宽的场景，50Mbps 跑不动。
- 大型游戏服务器不合适，CPU 和带宽都不是为这个准备的。
- 需要 DDoS 高防的业务别放这里。韩国机房不像狗云美国洛杉矶机房那样自带防御。
- 1GB 内存的 KR.S 不建议装 Windows，2GB 及以上的方案才适合。

这些需求对应的替代方向是狗云香港 MG 系列（在售配置最高到 250Mbps、500Mbps 档）或重庆机房（100Mbps 联通骨干）。跨境店群、ERP 后台、代理中转、韩区流媒体、个人建站这几类，韩国机房的 87ms 和本地 IP 才是优势所在。

## 常见问题

**经典云一直售罄，是不是买不到了？**

页面显示售罄就是当前没有库存，补货时间没有公开规律。弹性云是常开入口，配置能自定义，电信去程还是 CN2，售罄时不用等。

**流量跑完会停机吗？**

不会。经典云流量用完后带宽降到最低档，网站仍可访问，下个计费月流量自动清零。弹性云超出免费额度按 ¥0.10/GB 计费。

**三天退款具体是什么条件？**

开通三日内、IP 完好、流量使用不超过 5%、无违规操作，可以发工单申请销毁，系统按比例扣除使用费后把余额退回账户。弹性云的预付费余额可以随时原路退回。关于七日内能销毁几次，两份资料一份写“不超过两次”、一份写“最多三次”，无法确认哪个更新，下单前问一下客服更稳妥。

**IP 是原生 IP 吗？**

归属地是韩国首尔，本地服务和流媒体会识别为韩国用户。是否“原生”按各平台自己的判定标准，个别平台可能不解，以实测为准。

**能装 Windows 吗？**

2GB 内存及以上的方案支持，1GB 的 KR.S 建议用 Linux。
